# 操作系统处理机调度模拟系统

一个用于模拟经典进程调度算法运行过程的桌面应用，支持可视化展示调度结果。

## 功能特性

### 三种调度算法
- **FCFS（先来先服务）**：按进程到达顺序执行，非抢占式
- **SRTF（抢占式最短剩余时间优先）**：每次选择剩余服务时间最短的进程
- **RR（时间片轮转）**：支持自定义时间片，时间片用完则回到就绪队列

### 界面功能
- 📋 **进程管理**：手动添加/删除/清空进程，支持随机生成测试数据
- 📊 **甘特图**：Matplotlib 绘制，支持动态刷新和导出PNG
- 📋 **实时状态表**：显示每个进程的时钟、状态、已运行时间等
- 📈 **性能指标**：自动计算周转时间、带权周转时间、CPU利用率、吞吐量
- 📝 **调度日志**：彩色滚动日志，记录每个调度事件

### 高级功能
- 🎮 动画演示：支持开始/暂停/继续/重置
- ⚡ 速度调节：可调节动画播放速度
- 💾 导出甘特图为PNG图片
- 🎲 随机生成测试数据

## 算法介绍

### FCFS（First Come First Served）
按进程到达的先后顺序依次执行。优点是简单公平，缺点是对短进程不友好（"护航效应"）。

### SRTF（Shortest Remaining Time First）
SJF 的抢占版本。每当新进程到达或当前进程完成时，选择剩余服务时间最短的进程执行。
平均等待时间最短，但可能导致长进程"饥饿"。

### RR（Round Robin）
每个进程获得固定长度的时间片。时间片用完后，进程被移到就绪队列末尾。
适合分时系统，公平性好，但时间片选择影响性能。
